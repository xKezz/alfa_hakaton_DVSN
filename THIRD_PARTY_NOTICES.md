`alfa-hakaton-DVSN`. Точные версии Python-пакетов — в
`src/backend/requirements.txt`, frontend — в `src/front/package-lock.json`.

## 4. Данные

| Набор                                                    | Характер                                  | Источник / лицензия                                        |
| -------------------------------------------------------- | ----------------------------------------- | ---------------------------------------------------------- |
| `src/db/df_companies.csv`                                | 127 828 синтетических записей компаний    | сгенерирован для проекта; не является реальным реестром    |
| `src/db/df_financial.csv`                                | 127 828 синтетических годовых отчётностей | сгенерирован для проекта; не является реальной отчётностью |
| `src/db/setup_db.py` (`DEMO_COMPANIES`, `LOAN_PRODUCTS`) | 4 демо-компании, 11 продуктов             | синтетические тестовые данные проекта                      |
| `src/credit_risk/data/weight.json`                       | веса и пороги скоринга                    | конфигурация проекта; значения экспертные/калибровочные    |

Синтетические данные не содержат персональных данных и не являются
официальной отчётностью или офертой. Синтетические данные собраны с сайта https://tochno.st/datasets/rfsd - сайт с Российской базы бухгалтерской отчетности. Веса взяты с  АКРА «Методология присвоения кредитных рейтингов нефинансовым компаниям по национальной шкале для Российской Федерации». 

## 5. Модели и алгоритмы

- ML/LLM-модели не используются.
- Кредитный рейтинг рассчитывается детерминированной формулой
  `src/credit_risk/credit_risk_score.py`; параметры вынесены в `weight.json`.
- Методические материалы в `src/credit_risk/README.md` подготовлены с
  использованием публично описанных подходов (в тексте указан источник АКРА);
  сторонний исполняемый код или закрытые данные не включены.

## 6. Смоделированные интеграции

| Интеграция                           | Как смоделирована                                                   | Ограничение                           |
| ------------------------------------ | ------------------------------------------------------------------- | ------------------------------------- |
| ФНС API                              | `src/credit_risk/apis_fns_example.py` + локальная PostgreSQL        | реальные запросы в ФНС не выполняются |
| Банковское ядро / кредитные продукты | таблица `loan_catalog`, синтетические продукты и офферы             | нет интеграции с АБС/скоринговым бюро |
| Аутентификация                       | локальная таблица `login`, SHA-256-хеши и подписанные Bearer-токены | нет внешнего IdP/SSO                  |
## 7. Примечание

Перед внешним распространением необходимо проверить происхождение и права на
полный синтетический датасет `src/db/df_*.csv` и методические материалы
`src/credit_risk/README.md`. В репозитории не указана отдельная лицензия проекта.
